# Supaplex for Android 1.2 — withdrawn

This historical release bundled original game data. Its downloadable APK and source archive have been withdrawn. Use version 1.4 or later, which requires your own PC/DOS game files. See [game-data setup](GAME-DATA.md).

The open-source port is a separate project from the Android version on Google Play. Code licenses and original authorship remain credited in [third-party notices](../THIRD_PARTY_NOTICES.md).
